## 六、测试中发现并修复的问题

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | 后端启动失败（BUILD FAILURE） | application.yml 中密码以 @ 开头未加引号，YAML 解析异常 | 密码加引号，并拆分到 application-local.yml |
| 2 | 登录返回 code=5000 | 本机 Redis 需要密码（requirepass），配置为空 | application-local.yml 补充 Redis 密码 |
| 3 | 功能测试中文变成 ? / 乱码 | Windows PowerShell 发送 JSON body 时默认非 UTF-8 | 测试脚本改用 Node.js 原生 fetch（UTF-8） |

## 七、遗留说明

1. 浏览量回写为定时任务（每 60 秒），测试未做长周期观察，逻辑已通过「Redis 增量返回」验证。
2. 文件/图片上传未实现（封面使用图片 URL 文本），后续可作为增强项。
3. 前端页面已通过 HTTP 层验证可访问，未做人工浏览器视觉走查（建议你打开 5173 实际点一遍）。
4. 限流采用固定窗口计数，登录测试会占用额度；重复执行测试前建议等待 1 分钟。
